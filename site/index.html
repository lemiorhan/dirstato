See what is eating your disk. Same numbers as du.

dirstato is a fast, read-only disk usage explorer for the macOS terminal. Walk your folders as a tree or one at a time; every size is counted the way du -skx counts it.

$ brew install lemiorhan/dirstato/dirstato█

Disk usage, not file length
Each entry counts st_blocks × 512, so a sparse file counts what it actually occupies. A folder's own blocks count too.
Hard links count once
When several paths share an inode, the path that sorts first carries the bytes and the others show 0.
Symlinks are not followed
A symlink counts as itself. Only the root is resolved: pass a symlink to a folder and its target is scanned.
One file system
The scan does not descend into folders on another device, such as mounted volumes.
Unreadable folders are marked
They get a !, keep their own blocks, and the scan goes on.

Pinned by tests that compare dirstato with /usr/bin/du on fixture trees with hard links, symlinks, sparse files, unreadable folders and a mounted disk image: scan_eval_test.go.

Four times faster than du. Measured once.

Folders are scanned in parallel, and every node stays in memory so sorting and filtering are instant afterwards.

There is no delete key. dirstato tells you where the space went; you decide what to do about it.

Install

dirstato runs on macOS only: it reads file system metadata through macOS system calls and copies with pbcopy.

# Homebrew. The tap builds from source; Homebrew installs Go for the build.

$ brew install lemiorhan/dirstato/dirstato

# Go 1.27 or newer

$ go install github.com/lemiorhan/dirstato@latest

# From source

$ git clone https://github.com/lemiorhan/dirstato.git && cd dirstato && go build -o dirstato .

# Then point it at a folder

$ dirstato                      # scan the current folder
$ dirstato ~/Library --min 1G   # only items of 1 GiB or more
$ dirstato /Applications
